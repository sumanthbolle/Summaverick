Research agent · internal demo

Ask a ServiceNow question.

A retrieval agent over the ServiceNow product documentation. It shows you the passages it found, tells you how well they match your question, and says plainly what it did not check.

Honest status: this deployment has no answer model configured, so the agent returns the matching documentation passages rather than prose. When a model key is set it writes an answer from those passages and every sentence is checked back against them. It has no access to any ServiceNow instance.

Four questions with reviewed results:

What this agent does and does not do

  • Scope. The ServiceNow product documentation for the current release family, plus the Fluent SDK documentation. Nothing outside ServiceNow, and no instance data.
  • Relevance. Reported per run as the share of your question's distinctive terms that the closest passage matched. A weak match is labelled weak.
  • Groundedness. Only checked when a model wrote an answer, and only as term overlap between each sentence and the cited passages. It does not test whether a sentence is true.
  • Completeness. Never assessed. Nothing here decides whether your question was fully answered.
  • Injection handling. Questions matching known prompt-injection patterns are rejected before any model call, and retrieved text is always treated as data rather than instructions. Both are pattern-based defences, not guarantees.
  • Limits. Six questions a minute and fifty a day per browser.
