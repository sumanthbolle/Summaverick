Research agent

Ask a ServiceNow question.

You will see how it works as it works: how it read your question, where it looked, what it refused to trust, and the source behind every part of the answer.

It only knows ServiceNow — the Fluent SDK, the product docs, and (off by default) read-only instance metadata. There is a request limit, and anything that looks like a prompt-injection attempt is turned away before it reaches a model. With no model key configured you still get the draft assembled from the evidence.
