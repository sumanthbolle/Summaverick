What is ServiceNow Now Assist? A Beginner Guide with Real Enterprise Examples

Beginner · 25 min read · Mar 2026

Now Assist in Plain English

If you have used ChatGPT, Copilot, or any AI assistant at home, you already understand the basic idea behind Now Assist. Now Assist is ServiceNow's built-in AI assistant that helps employees and support agents work faster by summarizing information, suggesting responses, generating content, and finding answers — all within the ServiceNow platform they already use every day.

The critical distinction: Now Assist is not a separate chatbot you deploy and maintain. It is embedded directly inside ServiceNow workflows — inside the incident form, the knowledge base, the service catalog, the HR case, the customer service interaction. When an agent opens a ticket, AI suggestions appear right there. When an employee searches the portal, AI-enhanced answers appear automatically. There is no separate tool to log into.

The Simplest Way to Think About It

Think of Now Assist as three AI assistants in one:

AssistantWho It HelpsWhat It DoesReal Example
Agent AssistSupport agents (IT, HR, Customer Service)Summarizes case history, suggests responses, drafts resolution notes, recommends similar past incidentsAn L1 agent opens a ticket with 47 comments spanning 3 weeks. Instead of reading everything, they click "Summarize" and get a 5-line summary of the issue, actions taken, and current status in 3 seconds.
Requester AssistEmployees / End usersHelps people find answers and submit better requests through the self-service portalAn employee types "my VPN is not connecting" in the portal. Instead of just showing search results, Now Assist generates a direct answer: "Try these 3 steps first..." with a link to the full KB article.
Creator AssistDevelopers and admins building on the platformGenerates code, flows, catalog items, and playbooks from natural language descriptionsA developer types "create a flow that sends a Slack notification when a P1 incident is created" and Now Assist generates the Flow Designer configuration.

Every Now Assist Skill — What It Actually Does

Now Assist is organized into skills — individual AI capabilities that can be turned on or off per module. Think of skills like apps on your phone: you enable the ones you need.

The skills fall into four families. ITSM skills help IT agents: incident, chat, and change summarization, resolution notes generation, KB article generation, and suggested chat replies. HRSD and CSM skills apply the same ideas to HR cases and customer cases, adding CSM-specific capabilities like email reply drafting and voice call summarization. Creator skills help builders: flow generation, code assist, and catalog item, playbook, app, and dashboard generation from natural language.

For the full skill-by-skill breakdown — what each skill does, where it appears in the UI, and how to configure it — see the companion post "Now Assist Skills Deep Dive: Every Skill, Every Module, and How to Set Them Up" on this blog.

How Now Assist Works Under the Hood

Understanding the architecture helps you troubleshoot when AI suggestions are poor and explain to stakeholders why certain things work or do not work.

The Flow of an AI Request

User clicks "Summarize" on an incident
        ↓
Now Assist reads the incident data:
  - Work notes, comments, activity log
  - Related records (tasks, CIs, changes)
  - Knowledge articles linked to the incident
        ↓
ServiceNow constructs a prompt:
  - System instructions + context data + user request
  - Guardrails applied (PII filtering, topic restrictions)
        ↓
Prompt sent to LLM (Large Language Model):
  - ServiceNow's own LLM infrastructure (Now LLM)
  - OR configured third-party model (Azure OpenAI)
        ↓
LLM generates response
        ↓
Response filtered through guardrails:
  - PII detection, harmful content check
  - Relevance verification
        ↓
Summary displayed to user in the Now Assist panel
  - User can accept, edit, or dismiss

Key Architecture Concepts

ConceptWhat It MeansWhy It Matters
Now LLMServiceNow's own large language model, hosted on ServiceNow infrastructureYour data stays within ServiceNow's boundary — no third-party data exposure. This matters for compliance-sensitive industries (healthcare, finance, government).
SkillsIndividual AI capabilities that can be enabled/disabled per moduleYou control exactly which AI features are active. Enable summarization for ITSM but not for HRSD if you want to phase the rollout.
GuardrailsRules that filter what goes into prompts and what comes out of responsesPrevents the AI from exposing PII (names, SSNs, emails) in generated text and blocks off-topic or harmful content.
Context GroundingThe AI response is grounded in actual ServiceNow data (incident notes, KB articles), not just general knowledgeReduces hallucination — the AI cites actual records instead of making things up. This is why clean data matters: garbage in = garbage out.
Now Assist Admin ConsoleThe centralized administration hub where you manage all AI settingsOne place to enable skills, review usage analytics, configure guardrails, and manage LLM connections.

Setting Up Now Assist — Step by Step

This is the practical setup path for a ServiceNow admin enabling Now Assist for the first time:

Step 1: Verify Your Instance Version

// Navigate to: your-instance.service-now.com/stats.do
// Check "Build name" on stats.do — Australia is the current family.
// Now Assist skills began shipping in earlier releases and expand each family
// (Skill Kit, AI Agents, AI Control Tower). Confirm which skills ship on your build
// via the release notes for that family.

Step 2: Open the Now Assist Admin Console

// Navigate to: All > Now Assist > Now Assist Admin
// This is the central hub for all AI configuration.
//
// What you will see:
// - Dashboard: usage metrics, active skills, model status
// - Skills: list of available skills by module (ITSM, HRSD, CSM, Creator)
// - Settings: plugin management, LLM configuration, data sharing controls
// - Analytics: how often skills are used, acceptance rates, feedback

Step 3: Install the Now Assist Applications

// Now Assist capabilities ship as applications, not classic plugins.
// Install the one for each workflow you own:
//   Now Assist for ITSM     → incident summary, resolution notes
//   Now Assist for HRSD     → HR case summary
//   Now Assist for CSM      → customer case summary, email reply
//   Now Assist for Creator  → code assist, flow generation
//
// Install and update them from the ServiceNow Store, or on the
// instance via System Applications > Application Manager.
// The Now Assist Admin console manages them once installed and licensed.

Step 4: Enable Your First Skills

// In the Now Assist Admin Console:
// 1. Go to the Skills section
// 2. Find "Incident Summarization" (a good first skill — low risk, high visibility)
// 3. Click to enable
// 4. Configure:
//    - Which roles can use it (e.g., itil, admin)
//    - Whether it auto-runs or requires user click
//    - Any additional guardrail settings
// 5. Save and test with a sample incident

Step 5: Test and Validate

// Open an incident with a substantial work note history
// Look for the Now Assist panel (usually right side of the form)
// Click "Summarize"
// Review the generated summary:
//   - Is it accurate?
//   - Does it capture the key points?
//   - Does it expose any sensitive data it shouldn't?
// If satisfied, expand to more users; if not, check data quality.

Where Teams Get Confused — Common Misconceptions

MisconceptionReality
"Now Assist will fix our broken processes"AI amplifies what you already have. If your incident categorization is a mess, AI suggestions will be a mess. Fix processes first, then add AI.
"We need to train the AI on our data"Now Assist uses pre-trained models plus your instance data as context. You do not train a custom model — you configure skills and ensure your data (KB articles, work notes) is clean and complete.
"Now Assist replaces L1 support agents"It augments them. Agents still review, approve, and edit AI-generated content. Now Assist handles the tedious parts (reading 50 comments, drafting notes) so agents can focus on judgment and empathy.
"AI suggestions are always accurate"They are usually helpful but not always correct. That is why every AI output has an accept/edit/dismiss option. Treat AI suggestions like a junior colleague's draft — review before using.
"We can enable everything at once"Phased rollout is critical. Start with 1-2 high-volume, low-risk skills (like incident summarization), measure results, then expand. Trying to enable all skills on day one overwhelms users and makes it impossible to measure impact.

The Data Quality Foundation

This is the single most important factor in Now Assist success. The AI generates responses based on what is in your ServiceNow data. If your data is poor, the AI output will be poor.

Data AreaWhat "Good" Looks LikeWhat "Bad" Looks LikeImpact on Now Assist
Work NotesDetailed, timestamped notes describing what was done and why at each stepEmpty or one-word notes like "done" or "fixed"Summarization is only as good as the notes. No notes = nothing to summarize.
Knowledge BaseWell-structured articles with clear steps, updated regularly, covering common issuesOutdated, incomplete, or nonexistent KB articlesKB Generation and Search Assist depend on existing knowledge quality. AI cannot create good articles from nothing.
CategorizationConsistent use of categories and subcategories with clear definitionsIncidents miscategorized or left as "Other/General"AI recommendations for routing and resolution depend on pattern matching against historical data. Bad categorization = bad patterns.
Resolution NotesClear description of what fixed the issue and what the root cause wasCopy-paste of the short description or "Resolved per user"Resolution Notes Generation learns from past closures. If past closures are garbage, generated notes will be too.

The #1 Rule of Now Assist

AI quality follows data quality. Before enabling Now Assist, audit your knowledge base, work note practices, and categorization standards. Spend 2 weeks cleaning data before spending 2 days enabling skills. The ROI difference is dramatic.
