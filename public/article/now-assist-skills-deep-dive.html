Now Assist Skills Deep Dive: Every Skill, Every Module, and How to Set Them Up

Intermediate · 25 min read · May 2026

What This Article Covers

Now Assist is organized into skills — individual AI capabilities grouped by product module. Each skill can be independently enabled, configured, and monitored. This article is the complete reference: every skill, what it does, which plugin powers it, where it appears in the UI, and how to set it up.

The Now Assist Admin Console — Your Control Center

Before diving into individual skills, you need to know where everything is managed.

// Access the Admin Console:
// Navigate to: All > Now Assist > Now Assist Admin
//
// What you see:
// ┌─────────────────────────────────────┐
// │  Dashboard                           │ → Usage stats, active skills, model health
// │  Skills                              │ → Enable/disable/configure individual skills
// │  Settings                            │ → Plugins, LLM config, data sharing
// │  Analytics                           │ → Acceptance rates, feedback, trends
// │  Generative AI Controller            │ → Guardrails, PII rules, topic restrictions
// └─────────────────────────────────────┘

ITSM Skills (IT Service Management)

Install: the Now Assist for ITSM application (ServiceNow Store / Application Manager)

These skills are designed for IT support agents who handle incidents, problems, and changes.

Incident Summarization

What it does: Reads the entire history of an incident — work notes, additional comments, activity log, state transitions, and related records — and generates a concise human-readable summary.

Where you see it: The Now Assist panel on the right side of the incident form in Agent Workspace. Agent clicks "Summarize" and the summary appears within seconds.

When it is most valuable: Complex incidents with dozens of comments spanning days or weeks. Escalated incidents where the new agent needs context fast. Shift handoffs where the incoming agent needs to catch up on all active P1s.

Data dependency: Quality depends entirely on work note quality. If agents write detailed, structured notes, summaries are excellent. If work notes are empty or say "called user, waiting," the summary will reflect that emptiness.

Resolution Notes Generation

What it does: When an agent resolves an incident, this skill drafts the close notes based on the work notes, actions taken, and resolution approach. The agent reviews the draft, edits if needed, and saves.

Where you see it: The Resolution Information section when the agent changes state to Resolved.

Why it matters: Consistent, complete resolution notes are critical for knowledge management and trend analysis. Most agents write minimal close notes when pressed for time. AI-generated drafts ensure every ticket has useful closure documentation.

Chat Summarization

What it does: Summarizes a live chat or Virtual Agent conversation transcript. Particularly valuable when a chat gets transferred from Virtual Agent to a live agent, or from one agent to another.

Where you see it: Agent Workspace chat panel.

Chat Reply Recommendation

What it does: During a live chat, suggests a response for the agent based on the conversation context and knowledge base content. The agent can accept the suggestion, modify it, or ignore it.

Where you see it: Below the chat input field — "Suggested reply" text that the agent can click to insert.

Data dependency: Quality depends on knowledge base coverage. If there are good KB articles for the topic being discussed, recommendations are strong. If the KB is sparse, recommendations will be generic.

KB Article Generation

What it does: After resolving an incident, drafts a knowledge base article from the incident details and resolution. The idea: if this incident was resolved, the solution should be captured so the next person with the same issue can self-serve.

Where you see it: Post-resolution action — a "Create KB Article" option that generates a draft article.

Change Request Summarization

What it does: Summarizes complex change requests — particularly useful for CAB (Change Advisory Board) reviewers who need to understand the change, its risk, and its impact without reading every detail.

Sidebar Discussion Summarization

What it does: Summarizes sidebar chat discussions (collaboration chats) that occurred during incident resolution, so team members joining later can catch up.

HRSD Skills (HR Service Delivery)

Install: the Now Assist for HRSD application (ServiceNow Store / Application Manager)

Same core capabilities as ITSM but tailored for HR workflows. Key difference: HR data is more sensitive (PII, compensation, health), so guardrail configuration is critical.

HR Case Summarization

Same concept as Incident Summarization but for HR cases — benefits disputes, accommodation requests, employee relations issues.

Resolution Notes Generation

Drafts closure documentation for HR cases.

Chat Summarization & Reply Recommendation

Supports HR chat interactions — particularly important for live agent handoffs during sensitive conversations.

KB Article Generation

Generates HR knowledge articles from resolved cases — "How to update tax withholding," "Steps to request FMLA leave."

Privacy Note

HR data often contains PII and sensitive information. Before enabling HRSD skills, configure the Generative AI Controller to ensure PII is properly handled — names, SSNs, salary information, and health data should be filtered from AI prompts where appropriate.

CSM Skills (Customer Service Management)

Install: the Now Assist for CSM application (ServiceNow Store / Application Manager)

Designed for customer-facing support teams.

Customer Case Summarization

Summarizes customer support cases — essential when cases span multiple agents, channels (chat, email, phone), and weeks of back-and-forth.

Email Reply Recommendation

Unique to CSM: Drafts email responses to customer inquiries. The AI considers the case history, product context, and KB articles to generate a professional, contextual reply. The agent reviews and sends.

Voice Call Summarization

Unique to CSM: When phone calls are transcribed, this skill summarizes the transcript into key points, action items, and next steps.

Chat Reply Recommendation & Chat Summarization

Same as ITSM equivalents but configured for customer-facing conversations — tone and language are adjusted for external communication.

Creator Skills (For Developers and Admins)

Install: the Now Assist for Creator application (ServiceNow Store / Application Manager)

These skills help people build on the platform faster.

Flow Generation

What it does: Describe a flow in natural language ("create a flow that sends a Slack notification when a P1 incident is created and the assignment group is empty") and AI generates the Flow Designer configuration.

Where you see it: Flow Designer — natural language input field.

Code Assist (Intelligent Code Recommendations)

What it does: AI-powered code completion in the ServiceNow script editor. Suggests the next lines of code, explains existing scripts, and generates GlideRecord queries from descriptions.

Where you see it: Script editor across the platform — Business Rules, Script Includes, Client Scripts, etc.

Catalog Item Generation

What it does: Describe a catalog item and AI generates the item configuration including variables, workflow, and approval rules.

Playbook Generation & Recommendation

What it does: Generates process playbook steps from descriptions and recommends playbook templates based on the use case.

App Generation

What it does: Generates a starter application structure from a plain-English description of what the app should do.

Data Visualization Generation

What it does: Creates dashboards and report visualizations from natural language — "show me P1 incidents by assignment group over the last 6 months as a line chart."

The Skill Kit — Building Custom Skills

When the out-of-box skills do not cover your use case, the Now Assist Skill Kit lets you build custom skills. This is an intermediate-to-advanced capability.

// What you can do with the Skill Kit:
//
// 1. Define a custom prompt template
//    - System instructions + data context + user request
//    - Example: "Summarize this change request focusing on risk factors"
//
// 2. Connect custom data sources
//    - Pull from any ServiceNow table (not just OOB ones)
//    - Include related record data, custom fields, attachments
//
// 3. Deploy to Now Assist panel or Context Menu
//    - Appears alongside OOB skills in the Agent Workspace
//    - Or as a right-click option on text fields (Elaborate, Shorten, Analyze)
//
// 4. Use Automated Prompt Optimization (APO)
//    - Feed a dataset of 100+ records
//    - APO reviews skill performance and suggests prompt improvements
//    - Measures: correctness, faithfulness, latency
//
// 5. Integrate Predictive Intelligence
//    - Add ML classification models to custom skills
//    - Combine generative AI (text) with predictive AI (classification)

Guardrails and Governance

Before enabling skills at scale, configure the Generative AI Controller:

// Navigate to: Now Assist Admin > Generative AI Controller
//
// Key configurations:
// 1. PII Handling
//    - Mask PII in prompts (names, emails, SSNs, phone numbers)
//    - Configure which PII types to mask vs. allow
//
// 2. Topic Restrictions
//    - Block AI from generating content on certain topics
//    - E.g., "Do not generate content about legal advice"
//
// 3. Response Quality
//    - Max response length
//    - Required citation of source data
//    - Confidence threshold (below which AI declines to answer)
//
// 4. Audit Logging
//    - Every AI interaction logged
//    - What was sent to the model, what came back
//    - Who requested it, when, and what action they took (accept/edit/dismiss)

Implementation Advice

Start with one module (ITSM is usually the best first choice — highest volume, most mature data). Enable 2-3 skills for a pilot group. Measure acceptance rates and feedback for 4-6 weeks. Then expand to more skills and more modules. The phased approach consistently outperforms big-bang AI rollouts.
