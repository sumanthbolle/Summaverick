Virtual Agent from Zero: The Beginner-Friendly Guide to ServiceNow's Conversational AI

Beginner · 20 min read · May 2026

What is Virtual Agent?

Virtual Agent is ServiceNow's conversational chatbot — it lets employees interact with ServiceNow by typing (or speaking) in natural language instead of filling out forms. Think of it as the text-based equivalent of calling a help desk, but available 24/7 and capable of resolving many common requests instantly.

The Simplest Way to Understand It

Imagine an employee at your company needs to reset their password at 11 PM on a Saturday. Without Virtual Agent, they either wait until Monday or call an expensive after-hours support line. With Virtual Agent:

  1. Employee opens the ServiceNow portal or Teams/Slack
  2. Types: "I need to reset my password"
  3. Virtual Agent recognizes the intent ("password reset")
  4. Bot asks: "Which system? (Active Directory, SAP, Salesforce)"
  5. Employee selects "Active Directory"
  6. Bot verifies identity (security questions or MFA)
  7. Bot triggers an automated password reset workflow
  8. Employee gets a new temporary password in under 2 minutes
  9. No human agent was involved. No ticket was created.

Key Components of Virtual Agent

Virtual Agent is built from several components that work together:

1. Topics

A topic is a single conversation flow for one specific task. "Reset password," "Check ticket status," "Request a laptop" — each is a separate topic. Think of each topic as a mini-program: it has a trigger (what the user says), a conversation flow (what the bot asks and does), and an outcome (resolution or escalation).

2. NLU (Natural Language Understanding)

NLU is what makes Virtual Agent understand what the user means, not just what they typed. When a user says "my password doesn't work," "can't log in," or "locked out of my account" — NLU maps all of these to the same intent: password reset.

ConceptWhat It IsExample
IntentWhat the user wants to do"Reset password," "Check order status," "Report an issue"
UtterancesThe different ways users express the same intent"I forgot my password," "can't log in," "password expired," "locked out"
EntitiesSpecific data within the user's messageSystem name ("Active Directory"), location ("Building A"), device type ("laptop")
Confidence ScoreHow sure the AI is about its interpretation (0-100%)Above 80% → proceed with the matched topic. Below 50% → ask user to clarify.

3. Topic Blocks

Within a topic, the conversation is built from blocks — each block is one step in the conversation:

Block TypeWhat It DoesExample
TextBot sends a message to the user"I can help you reset your password."
User InputBot asks the user for information"Which system do you need the password reset for?"
ChoiceBot presents options for the user to selectButtons: [Active Directory] [SAP] [Salesforce]
DecisionBot branches based on a conditionIf system = "Active Directory" → go to AD reset flow; else → go to generic flow
ScriptExecute server-side JavaScriptLook up the user's account status, check if they have MFA enabled
Flow / SubflowTrigger a Flow Designer flowTrigger the "Reset Active Directory Password" subflow
Create RecordCreate a ServiceNow recordCreate an incident or request if the bot cannot resolve the issue
Agent TransferEscalate to a live agent"I am connecting you with a live agent who can help further."

4. Live Agent Handoff

Not every conversation can be resolved by the bot. When the bot cannot handle a request — either the confidence is too low, the topic is too complex, or the user explicitly asks for a human — Virtual Agent transfers the chat to a live agent in Agent Workspace. The agent sees the full conversation transcript so the user does not have to repeat themselves.

Virtual Agent + Now Assist + AI Agents: How They Connect

These three AI capabilities are related but serve different purposes:

Virtual AgentNow AssistAI Agents
What it isConversational chatbot for usersAI assistant for agents and creatorsAutonomous AI workers that execute tasks
Who it helpsEnd users / employeesSupport agents, developers, adminsThe system itself (reduces human involvement)
How it worksUser chats → bot understands intent → follows topic flow → resolves or escalatesAgent opens ticket → AI summarizes, suggests, drafts → agent reviews and actsTrigger fires → AI Agent reasons about steps → executes actions → updates record
Level of autonomyGuided (follows pre-built topic flows)Assistive (suggests, human decides)Autonomous (AI decides and acts within guardrails)
ExampleUser asks "reset my password" → bot resets itAgent clicks "Summarize" → AI generates summary → agent uses itP1 incident created → AI Agent identifies root cause, routes to team, sends notification — no human triggered these steps

How they work together: A user chats with Virtual Agent (front door). If the bot cannot resolve, it creates a ticket and escalates to a live agent. The live agent uses Now Assist (AI suggestions, summaries) to resolve faster. For routine patterns that happen thousands of times, AI Agents can handle the entire process autonomously — from the initial chat to the final resolution — with no human involvement.

Building Your First Topic — Step by Step

// Navigate to: All > Virtual Agent > Topic Conversation Design
// Click "New" to create a topic
//
// 1. SETUP
//    Name: "Reset Password"
//    Category: IT Support
//    NLU Intent: password_reset (link to your NLU model)
//    Sample utterances: "I forgot my password", "can't log in",
//                       "locked out", "password expired", "reset pwd"
//
// 2. BUILD THE CONVERSATION FLOW
//    Block 1: Text — "I can help you reset your password."
//    Block 2: Choice — "Which system?"
//             Options: Active Directory, SAP, Salesforce, Other
//    Block 3: Decision — If "Active Directory" → go to Block 4
//                        If "Other" → go to Agent Transfer
//    Block 4: Script — Verify user identity (check user record, MFA status)
//    Block 5: Subflow — Trigger "Reset AD Password" Flow Designer subflow
//    Block 6: Text — "Your password has been reset. Your temporary
//                     password has been sent to your email."
//    Block 7: End conversation
//
// 3. TEST
//    Use the "Try it" panel on the right side of the designer
//    Type "I can't log in" and verify the bot follows the correct path
//
// 4. PUBLISH
//    Set topic to "Published" to make it live
//    Monitor in Virtual Agent Analytics
