the agent

Watch it work.

Ask a ServiceNow question. The trace shows each stage as it runs — how the query was classified, which layers were consulted, the dedup and injection checks, and the verified answer with its sources. If a question trips the injection detector, it's rejected before the model and you see that happen.

The trace streams live over SSE from the agent — rate-limited, and a query that trips the injection detector is blocked before the model. Try one to see it. (Served statically without the Worker, it falls back to a captured trace.)
